# Block 1: Computational Thinking & Python Foundations

**Duration:** Weeks 1-4  
**Core Question:** *How do we tell computers to think?*

---

## 🎯 Block Themes

This block introduces you to programming as a way of solving problems. You'll learn to break down complex tasks into logical steps and express them in Python code.

Programming isn't about memorizing syntax—it's about developing a new way of thinking. By the end of this block, you'll think like a programmer: breaking problems into steps, designing solutions, and expressing them in code.

---

## 📚 What You'll Learn

### Core Competencies
- **Think procedurally and algorithmically** - Break problems into steps
- **Write Python programs from scratch** - Express ideas in code
- **Use variables, functions, and control flow** - Build program logic
- **Debug and test your code** - Find and fix errors
- **Build a foundation** - Everything that follows builds on this

### Technical Skills
✅ Variables and data types  
✅ Operators and expressions  
✅ String manipulation and formatting  
✅ User input and validation  
✅ Conditional statements  
✅ Functions and parameters  
✅ Code organization and style

## 💡 Tips for Success

### Week by Week Strategy

**Week 1:** Focus on understanding concepts, not memorizing syntax  
**Week 2:** Practice daily—even 15 minutes helps  
**Week 3:** Start thinking in functions—every problem is a function  
**Week 4:** Review Weeks 1-3 to see how everything connects  

### Study Habits
1. **Type all code yourself** - Don't copy-paste
2. **Experiment** - Change values and see what happens
3. **Ask questions early** - Don't wait until you're stuck
4. **Form study groups** - Explain concepts to each other
5. **Complete exercises** - They give instant feedback

### Common Mistakes to Avoid
❌ Skipping exercises (you need the practice!)  
❌ Not reading error messages (they tell you what's wrong!)  
❌ Trying to memorize everything (focus on understanding)  
❌ Giving up when stuck (debugging is part of learning)  
❌ Working alone (programming is collaborative)
